# Yash Lawaniya — Data Analyst Portfolio

A responsive personal portfolio website built using HTML, CSS and JavaScript.

## Features

- Modern dark theme with cyan and violet gradients
- Responsive layout for desktop, tablet and mobile
- Animated background stars
- Animated hero illustration
- Scroll-reveal effects
- Mobile navigation menu
- About and skills sections
- Featured data analytics projects
- Experience and education timeline
- Contact links and resume button

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Run Locally

1. Keep `index.html`, `style.css` and `script.js` in the same folder.
2. Create an `assets` folder if it does not exist.
3. Place your resume PDF inside `assets/` and name it:

   `Yash_Lawaniya_Resume.pdf`

4. Open `index.html` in your browser.

Alternatively, open the folder in Visual Studio Code and run
the website using the Live Server extension.
